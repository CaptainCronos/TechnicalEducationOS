# Security

## Supported versions

| Version | Supported |
|---|---|
| `1.2.0-alpha1` | Yes |
| Earlier development snapshots | No |

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature for this repository. If it
is unavailable, contact the maintainer privately through the address published
on the maintainer's GitHub profile. Do not disclose the issue publicly until a
fix and disclosure plan are agreed.

Include affected versions, reproduction steps, impact, and any suggested
mitigation. You should receive an acknowledgment within seven days.

Do not commit secrets, passwords, private keys, tokens, private student data, or
environment files. Generated curriculum must be reviewed before instructional
use; content-quality concerns without a security impact belong in the public
issue tracker.
