# Curriculum mappings

Owns explicit reviewed relationships that cross authority boundaries, such as
standard-to-competency crosswalks, resource-to-objective mappings, and
legacy-record migration maps.

Inputs: stable, versioned IDs from knowledge, blueprint, model, or legacy
records plus reviewer decisions.  
Outputs: mapping records consumed by compilation, traceability, coverage, and
impact analysis.

Mappings are authoritative decisions, not disposable caches.
