# Course blueprints

Owns versioned course design records: course envelope, available instructional
time, meeting schedule, scope and sequence, competency allocation, assessment
windows, diagnostics, and approval.

Inputs: registered knowledge sources, institutional constraints, course
requirements, and review decisions.  
Outputs: approved blueprint packages consumed by curriculum-model compilation.

Blueprints do not contain document formatting or duplicate instructional
resource content. See the [Course Blueprint
Specification](../../docs/specifications/course-blueprint.md).
