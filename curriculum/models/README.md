# Structured curriculum models

Owns versioned, reviewed, renderer-ready curriculum meaning.

Inputs: an approved blueprint, reviewed knowledge references, mappings, and
authorized authoring decisions.  
Outputs: curriculum model packages, dependency manifests, validation results,
and trace graphs consumed by renderers and audits.

Only approved models may produce released educational artifacts. See the
[Curriculum Model
Specification](../../docs/specifications/curriculum-model.md).
