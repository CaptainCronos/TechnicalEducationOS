# Subsystem specifications

These documents define the required behavior and data responsibilities of each
curriculum compiler subsystem:

- [Knowledge Sources](knowledge-sources.md)
- [Course Blueprint](course-blueprint.md)
- [Curriculum Model](curriculum-model.md)
- [Canonical Lesson Model](canonical-lesson-model.md)
- [Educational Artifacts](educational-artifacts.md)
- [Traceability](traceability.md)

Machine-readable schemas in `../../schemas/` implement portions of these
contracts. The prose specification governs until a schema exists; once both
exist, inconsistencies are defects that require resolution.
