# Architecture

This path is retained for existing links. The governing architecture is the
[TEOS Architecture Overview](architecture/overview.md).

Its central constraint is:

> Registered knowledge informs an approved blueprint; the blueprint informs a
> structured curriculum model; only that model supplies educational content to
> renderers.

For detailed boundaries, see the [Repository Organization
Standard](architecture/repository-organization.md) and [Data Flow
Specification](architecture/data-flow.md).
