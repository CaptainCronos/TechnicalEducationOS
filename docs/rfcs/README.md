# Requests for Comments

RFCs are numbered design proposals governed by the
[RFC process](../RFC_PROCESS.md). Copy
[`0000-template.md`](0000-template.md), allocate the next unused four-digit
number, and submit it separately from the main implementation.

An accepted RFC describes intent. Normative current behavior remains in the
architecture, specification, compatibility, and API documentation linked by
that RFC.
