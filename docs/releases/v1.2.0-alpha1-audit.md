# v1.2.0-alpha1 release audit

Audit date: 2026-07-28

## Result

The proposed working tree is ready for maintainer approval as
`v1.2.0-alpha1`. No code, packaging, installation, documentation, licensing,
dependency, or artifact blocker remains. The changes are intentionally
uncommitted; no tag or remote GitHub release was created.

## Verification evidence

- 93 standard tests passed; 2 performance tests passed separately.
- Branch coverage is 85.58 percent against an enforced 85 percent floor.
- Ruff, JSON Schema validation, bytecode compilation, Markdown-link validation,
  and `git diff --check` passed without warnings or errors.
- Wheel, source-distribution, and editable installation succeeded in separate
  clean environments.
- Installed wheel and sdist CLI/API smoke tests passed outside the checkout.
- Both maintained reference configurations produced all 96 expected artifacts.
- Wheel and normalized sdist builds were byte-identical across two independent
  builds with the same source-date epoch.
- `twine check` passed and distribution contents contain only intended package
  code, metadata, README, and MIT license.
- All resolved runtime packages report MIT; `pip check` found no broken
  requirements.
- A current advisory query found no known vulnerabilities in the resolved
  runtime environment. The unpublished TEOS package itself cannot be looked up
  by a package-index advisory service.
