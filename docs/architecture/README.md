# Architecture

This directory defines system-wide TEOS boundaries:

- `overview.md` — components, authority, and lifecycle;
- `curriculum-compiler-philosophy.md` — governing compiler principles;
- `data-flow.md` — permitted transformations and approval gates; and
- `repository-organization.md` — directory ownership and input/output rules.

Subsystem data contracts live in `../specifications/`. Boundary changes require
an architecture decision record in `../decisions/`.
