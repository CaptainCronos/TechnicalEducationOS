# Standards represented by the reference course

The canonical v2 course contract stores human-readable standards in
`curriculum/course.json` and stores their stable mapping identifiers on each
competency. This directory is explanatory and does not introduce another source
record.

| Mapping ID | Reference | Use in this example |
|---|---|---|
| `OSHA.1910.334.c.1` | OSHA 29 CFR 1910.334(c)(1) | Suitability and inspection of test instruments |
| `NFPA70E.ESWP` | NFPA 70E electrically safe work practices | Safe measurement and diagnostic controls |
| `TEOS.EF-1` | TEOS Electrical Fundamentals EF-1 | Electrical quantity relationships |
| `TEOS.EF-2` | TEOS Electrical Fundamentals EF-2 | DC measurement and evaluation |
| `TEOS.EF-3` | TEOS Electrical Fundamentals EF-3 | Basic fault diagnosis |

The TEOS identifiers are illustrative internal outcomes. The two external
references are paraphrased for demonstration and do not replace the governing
standards.
