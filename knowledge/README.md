# Knowledge sources

Purpose: register the evidence and constraints that inform curriculum design.

Inputs are authoritative external sources and their metadata. Outputs are
versioned source manifests, addressable extracted records, provenance, and
review state consumed by course blueprints and curriculum models.

This directory does not contain course schedules, curriculum decisions, or
generated educational artifacts.

- `standards/` — required learning and performance expectations.
- `institutional/` — calendars, policies, and delivery constraints.
- `instructional/` — approved teaching resources and media.

See the [Knowledge Sources
Specification](../docs/specifications/knowledge-sources.md).
