# Institutions

Optional institution-specific configuration and presentation overlays live
here, separated from curriculum. Inputs are approved institution configuration
and branding values. Outputs are versioned configuration consumed by compiler
or presentation adapters. Overlays may provide presentation and administrative
labels but must not redefine curriculum objectives, instruction, labs,
assessments, or competencies.

The `j-tech` overlay is intentionally separate from the DSL204 course records.
Generation may include it with `--institution`; omitting it produces an
institution-neutral document from the same curriculum.
